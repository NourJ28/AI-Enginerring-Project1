StyleFit

Project Overview:
StyleFit is a web app that recommends outfits based on a user's personal style, the occasion, the weather and their preferences

Problem:
Choosing an outfit can be difficult when considering the weather and othe circumstances. StyleFit makes choosing outfits much easier

Core Features:
Select an occasion
Choose a style
Enter the weather conditions
Receive an outfit recommendation with clothing and shoes

Tech Stack:
React and Vite for the frontend
Node.js + Express for the backend
JSON for storing outfit options
GitHub Codespaces for development

Success Criteria:
Users can select an occasion, style and weather conditions and receive a suitable outfit recommendation

Potential Challenges:
Combining different user selections into useful outfit recommendations
